CONFIGURATION GUIDE

站点策略配置说明

传输模式

auto
按站点状态自动决策；未知站点先做 Range 资格验证。若实际使用 HLS 下载成功，系统会把该站点从 auto 学习为 hls。
hls
发现 HLS 媒体时优先使用浏览器 HLS 分段下载；没有 HLS 时回退 yt-dlp。
direct-range
普通直链文件优先使用 HTTP Range 多连接下载；仍必须通过基础 Range 探测，失败时回退 yt-dlp。
yt-dlp
强制跳过自定义 HLS 和 Direct Range，当前任务使用 yt-dlp 通用下载流程。

生命周期状态

UNKNOWN
新发现站点。后续任务默认使用 yt-dlp，并尝试一次当前任务的严格 Range 资格验证。
TASK_QUALIFIED
已有当前级资格验证成功证据，但后续每次任务仍重新验证，不获得永久 Direct Range 权限。
CANDIDATE
已累计多个不同视频和断点恢复成功证据，等待人工确认；仍执行任务级资格验证。
VERIFIED
人工或内置确认的可信站点。后续任务默认尝试 Direct Range，但基础 Range 探测仍不可跳过。
QUARANTINED
发生过内容不一致等严重异常，后续使用 yt-dlp 并保留已有断点，等待人工处理或重新验证。
DISABLED
人工完全禁用 Direct Range，后续任务强制使用 yt-dlp。

熔断状态

CLOSED
正常状态，策略可以按模式和生命周期状态生效。
OPEN
临时熔断，Direct Range 暂停，冷却结束前后续任务使用 yt-dlp。
HALF_OPEN
冷却后的试探状态，只允许一次小范围验证；成功转回 CLOSED，失败重新 OPEN。

TLS 后端

auto
优先使用 httpx；遇到 TLS 协议错误或浏览器指纹拒绝时自动切换 curl_cffi Chrome 指纹。
httpx
只使用 httpx，不在 TLS 失败时自动切换；适合明确支持普通 Python HTTP 客户端的站点。
curl_cffi
直接使用 curl_cffi 和 Chrome TLS 指纹，适合 Cloudflare 或严格 TLS 指纹校验的 CDN。

视频选择策略

视频选择先确认“哪个媒体是当前页面的主视频”，再决定使用哪个清晰度。 它和传输模式相互独立：视频选择负责候选与清晰度，传输模式负责如何下载。

策略预设
可以选择 generic、xHamster、xVideos、Porntrex、PornOne 或 TNAflix 预设。选择预设后会带出对应默认值，仍可继续单独修改各项配置。
用户自定义优先
用户保存的站点媒体策略优先于站点内置预设；站点没有用户配置时使用内置预设，没有对应内置预设的站点使用 generic 兜底。
媒体来源顺序
按从上到下的顺序优先选择候选来源。可配置 player-config、network、video-element、performance；前面的来源会优先于后面的来源。
视频身份校验
site_default 优先使用能匹配当前页面视频身份的候选；page_id 要求必须匹配页面视频身份；loose 会放宽身份过滤，只建议用于确实无法识别页面 ID 的特殊站点。
媒体类型顺序
决定优先使用 hls、dash 还是 file。例如 HLS 优先适合分段流媒体，file 优先适合已验证的直链 MP4 站点。

清晰度与兜底配置

默认清晰度
下载任务选择“跟随站点策略”时使用该目标。auto 表示在允许范围内选择最高可用清晰度；1080p、720p、480p、360p 表示优先目标档位。
优先最近的较低档
没有目标档位时，先尝试低于目标的最高可用档位；如果没有任何较低档位，再使用范围内的其他可用档位。
最接近的可用档位
没有目标档位时，同时比较较低和较高档位，选择与目标差异最小的分辨率。
仅使用精确档位
不允许自动降级或升级。来源没有目标档位时该候选不可用，继续尝试其他候选或兜底流程。
最低 / 最高清晰度
限制自动选择范围，范围为 240p–2160p，最低值不能大于最高值。站点默认仍建议保持 1080p，只有明确选择 4K 时才提高任务上限。
低于最低档位时允许自动兜底
开启后，如果没有达到最低清晰度的媒体，auto 模式可以使用现有最佳画质；关闭后则拒绝低于最低档位的候选。
播放按钮选择器
可选 CSS 选择器。页面不会自动播放或播放器创建较晚时，可以指定需要点击的播放按钮。留空表示使用自动播放按钮识别。
允许 yt-dlp 页面解析兜底
媒体嗅探没有找到候选时，允许把原网页交给 yt-dlp 继续解析。该兜底只处理发现阶段，不会绕过内容身份校验和广告文件检查。

保存、试运行与任务快照

试运行当前策略
在站点详情页输入该站点下的网页地址，系统会打开页面、发现并排序候选，显示来源、类型、清晰度、是否匹配页面视频以及最终选择；试运行不会下载文件。
任务策略快照
创建下载任务时保存当时的媒体策略和版本。之后修改站点策略不会影响已经创建或正在重试的任务，避免同一断点在运行过程中改用另一套选择规则。
恢复站点默认
删除该站点的用户媒体策略，恢复站点内置预设；未知站点恢复为 generic 兜底。

传输模式是下一次任务的策略偏好；最近任务实际使用的传输方式显示在任务表的“传输”一栏。 媒体策略与传输策略的新配置只影响之后创建或尚未保存策略快照的任务，不中断当前下载任务，也不删除已有断点。

编辑站点策略

站点键 当前策略版本

状态修改说明

  • VERIFIED：后续默认尝试 Direct Range，需填写备注并记录人工批准。
  • UNKNOWN：清除永久 Direct Range 权限，后续任务重新资格验证。
  • CANDIDATE：仍对每次任务执行资格验证，不会跳过安全探测。
  • QUARANTINED：后续使用 yt-dlp，需填写隔离原因，已有断点不会删除。
  • DISABLED：后续强制使用 yt-dlp，不影响当前运行任务。
  • CLOSED：清除冷却和连续失败计数；OPEN：按冷却时间暂停 Direct Range；HALF_OPEN：下一次只允许一次验证。
  • 所有修改只影响下一次任务，不中断当前下载或播放。
